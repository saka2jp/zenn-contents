# エグゼクティブサマリー

## ATSを一言で

**ATS（Applicant Tracking System）** とは、採用プロセスを一元管理するSaaS型の採用管理プラットフォームであり、求人公開・応募受付・選考管理・内定・オンボーディング連携までの全工程をデジタル化するシステムである。

## 何を解決するか

| 課題 | ATSによる解決 |
|------|--------------|
| 大量の応募書類をメール/スプレッドシートで管理する限界 | 候補者データベースと選考パイプラインの一元管理 |
| 求人を複数媒体（LinkedIn・Indeed等）に個別掲載する手間 | ジョブボードへの一括配信API連携 |
| 面接官のフィードバックが散逸する | 評価スコアカードの構造化収集 |
| 採用活動の進捗が可視化されない | ファネル分析・Time-to-Hire等のメトリクス提供 |
| 人事システムとの二重入力 | HRIS/HCMとの自動データ連携 |

## 市場規模と状況

- 2025年のATS世界市場規模は約 **32.8億ドル**、2030年には **48.8億ドル**（CAGR 8.2%）に達する見込み（出典: [Mordor Intelligence](https://www.mordorintelligence.com/industry-reports/applicant-tracking-system-market)）
- クラウド型ATSが市場の **88.12%** を占める（2025年時点）
- 主要ベンダー上位10社で市場の **51.1%** を占有。iCIMSが10.7%でトップシェア（出典: [Apps Run The World](https://www.appsruntheworld.com/top-10-hcm-software-vendors-in-applicant-tracking-market-segment/)）

## 採用すべきケース

- 月間応募数が数十件を超え、スプレッドシート管理が破綻し始めている
- 複数の採用担当者・面接官が協調して選考を行う組織
- LinkedInやIndeed等への求人一括配信が必要なケース
- HRISやバックグラウンドチェックツールとの連携が必要な場合
- SOC2・GDPRなどのコンプライアンス対応が求められる企業

## 採用しない方がよいケース（アンチパターン）

- 年間採用数が数人以下の極小規模組織（コスト対効果が合わない）
- 採用プロセスを標準化したくない、職人的なハンドオフが中心の採用文化
- 完全に内製化されたHR技術基盤を持ち、ATSとのAPI統合リソースがない場合
- ATSベンダーへのデータロックインリスクを許容できないケース
