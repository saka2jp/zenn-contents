# 技術概要 — ATSのアーキテクチャ全体像

## システムの5層構造

モダンなATSは以下の5層で構成される（出典: [How ATS Work - CrawlJobs](https://www.crawljobs.com/blog/how-applicant-tracking-systems-work)）。

```
┌─────────────────────────────────────────────────────┐
│  Layer 1: 入力層                                     │
│  キャリアページ / 求人ボード / メール / 推薦 / 手動入力  │
└──────────────────────┬──────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────┐
│  Layer 2: レジュメパーシングエンジン                   │
│  OCR / NLP / Named Entity Recognition                │
└──────────────────────┬──────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────┐
│  Layer 3: 候補者データベース                           │
│  PostgreSQL（構造化データ）+ Elasticsearch（検索）     │
└──────────────────────┬──────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────┐
│  Layer 4: 検索・ランキング層                           │
│  ブール検索 / セマンティック検索 / スコアリング         │
└──────────────────────┬──────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────┐
│  Layer 5: ワークフローエンジン                         │
│  採用ステージ管理 / 自動通知 / 監査ログ / レポーティング │
└─────────────────────────────────────────────────────┘
```

## 主要コンポーネント

### データストア

| コンポーネント | 役割 | 代表技術 |
|------------|------|---------|
| リレーショナルDB | Job/Candidate/Application等のコアエンティティ | PostgreSQL, MySQL |
| 検索インデックス | 全文検索・フィルタリング | Elasticsearch, OpenSearch |
| オブジェクトストレージ | 履歴書PDFなどのファイル | AWS S3, GCS |
| キャッシュ | セッション・APIレスポンスキャッシュ | Redis |
| キュー | 非同期処理（メール送信・Webhook配信等） | RabbitMQ, SQS |

### APIレイヤー

- **Harvest API（Greenhouse）**: 内部データ読み書き（v3が現行。v1/v2は2026年8月廃止予定）（出典: [Greenhouse Support](https://support.greenhouse.io/hc/en-us/articles/10568627186203-Greenhouse-API-overview)）
- **Job Board API**: キャリアページ向けの求人データ公開
- **Webhook**: イベント駆動型のリアルタイム通知
- **Partner API**: 外部ツール連携（LinkedIn RSC、評価ツール等）

### マルチテナント基盤

SaaS型ATSは企業（テナント）ごとにデータを分離する必要がある。主要な分離パターンは後述の章で詳説する。

## 利用形態

ATSは以下3形態で提供される。

1. **Pure ATS SaaS**（Greenhouse、Lever）: 採用特化型。HRIS連携はAPI経由
2. **HCM組み込み型**（Workday、SAP SuccessFactors）: HCM全体の採用モジュール
3. **オープンソース/セルフホスト**（OpenCATS等）: 小規模・カスタマイズ重視

## 「最小構成」で動くもの

1. Job（求人）エンティティの作成
2. キャリアページへの埋め込みフォーム（Job Board API経由）
3. 応募受付 → Candidate + Application の自動生成
4. 選考ステージの手動更新
5. 合否通知メールの送信
